# API contracts

`openapi.json` is exported from FastAPI. `src/api.d.ts` is generated by the locked openapi-typescript tool. Do not edit either by hand.

From the repository root, `make contracts` regenerates both and `make contracts-check` fails if they drift (including before the first Git commit). The drift check generates candidates in a temporary directory and never edits source artifacts; OpenAPI export replaces its target atomically to preserve existing output on a failed write. `src/index.ts` exports named aliases for consumers. Only liveness/error contracts exist in 2A; business contracts arrive in 2B–2D. No runtime server or duplicated business schemas live here.

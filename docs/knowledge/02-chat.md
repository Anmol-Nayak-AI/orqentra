# Orqentra guide · How to use Chat
To use Orqentra chat, open your organization and select Chat in the sidebar. Choose a workspace. Open an existing conversation or select New chat. Type a question of at least three characters in the question box and select Send. Sending an empty box does not submit a message.

Orqentra retrieves relevant indexed knowledge and generates an answer. Queued or processing messages may take a short time. Expand Sources below an answer to read the supporting quotes. A new chat starts a separate private conversation; existing chats preserve their history.

Ask questions such as “How do I invite a teammate?”, “How does Orqentra use a vector database?” or “How do I request human help?” Product guides describe the application; organization-specific questions require that organization's approved knowledge. If no source answers the question, Orqentra should explain the gap rather than invent a policy or action.

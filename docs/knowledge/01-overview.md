# Orqentra guide · What is Orqentra?
Orqentra is an AI workforce platform with the tagline “Your workforce, intelligently orchestrated.” It brings organizations, shared workspaces, AI teammate definitions, knowledge, source-grounded chat, human support, tasks, reviews and activity history into one application.

The current development build includes Clerk sign-in, organization ownership, role permissions, PostgreSQL row-level security, pgvector knowledge retrieval, OpenAI-generated answers and explicit human handoff. It is a development/pilot implementation, not an approved production release. Some planned enterprise features are not implemented.

Use the organization selector to enter the correct team. Command Center shows the selected organization and accessible workspaces. Chat is for questions; Knowledge stores approved source text; Members manages real access; Audit trail explains recorded actions.

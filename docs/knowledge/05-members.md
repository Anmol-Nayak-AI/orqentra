# Orqentra guide · Real users, invitations and demo profiles
Real Orqentra users authenticate through Clerk. Creating fictional demo profiles does not create Clerk accounts or real memberships. Demo profiles have example.invalid email addresses and sample roles only; they cannot sign in, receive permissions, claim support chats or act as real teammates.

To invite a real person, open an organization and select Members. An OWNER/ADMIN can create a private single-use MEMBER or VIEWER invitation link valid for 48 hours. Share the link privately with the intended person; Orqentra does not send an email automatically. The recipient signs in through Clerk, opens the invitation and accepts it. Unavailable, expired, revoked or already used invitations cannot grant access.

An authorized owner can change a real member's role. Invite a person as MEMBER first, then promote them to ADMIN if they should handle human support. The last active owner cannot be removed or demoted. Membership removal withdraws access while preserving existing records. Never share passwords, session tokens or API keys in chat.
